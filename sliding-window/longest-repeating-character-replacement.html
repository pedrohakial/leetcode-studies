424. Longest Repeating Character Replacement (Medium)

https://leetcode.com/problems/longest-repeating-character-replacement/ · Tópico: Sliding Window (frequência + max)

Enunciado (resumo)

Dada uma string s de letras maiúsculas e um inteiro k, você pode trocar até k caracteres por qualquer outro. Devolver o tamanho da maior substring que dá para deixar com todos os caracteres iguais.

s = "ABAB", k = 2     →  4   (troca os dois A por B: "BBBB")
s = "AABABBA", k = 1  →  4   ("AABBBBA": o B do meio vira A)

Padrão — o que decorar

Janela deslizante + regra da validade: uma janela é válida se tamanho − frequência_do_char_mais_frequente ≤ k (o resto da janela é o que precisa ser trocado). Regra de ouro: quando ficar inválida, contrai a esquerda em 1 sem tocar no max_freq — o máximo histórico nunca desce, então a janela já não diminui mais; a resposta é len(s) − l no fim. Pista no enunciado: trocas limitadas + maior substring → janela com contagem de frequências, e o ingrediente final (max_freq) é o que torna O(n) em vez de O(26·n).

Python

class Solution:
    def characterReplacement(self, s: str, k: int) -> int:
        contagens: dict[str, int] = {}
        esquerda = 0
        maior = 0  # maior frequência de um char na janela
        for direita, c in enumerate(s):
            contagens[c] = contagens.get(c, 0) + 1
            maior = max(maior, contagens[c])
            largura = direita - esquerda + 1
            if largura - maior > k:
                contagens[s[esquerda]] -= 1
                esquerda += 1
        return len(s) - esquerda

Rust

#![allow(unused)]
fn main() {
pub fn character_replacement(s: String, k: i32) -> i32 {
    let bytes = s.as_bytes();
    let mut contagens = [0; 26];
    let (mut esquerda, mut maior_freq) = (0, 0);
    for (direita, &c) in bytes.iter().enumerate() {
        let i = (c - b'A') as usize;
        contagens[i] += 1;
        maior_freq = maior_freq.max(contagens[i]);
        let largura = direita - esquerda + 1;
        if largura as i32 - maior_freq > k {
            let j = (bytes[esquerda] - b'A') as usize;
            contagens[j] -= 1;
            esquerda += 1;
        }
    }
    (bytes.len() - esquerda) as i32
}
}

C++

#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    int characterReplacement(string s, int k) {
        int contagens[26] = {};
        int esquerda = 0, maior_freq = 0, melhor = 0;
        for (int direita = 0; direita < (int)s.size(); ++direita) {
            int i = s[direita] - 'A';
            contagens[i]++;
            maior_freq = max(maior_freq, contagens[i]);
            int largura = direita - esquerda + 1;
            if (largura - maior_freq > k) {
                contagens[s[esquerda] - 'A']--;
                esquerda++;
            }
            melhor = max(melhor, direita - esquerda + 1);
        }
        return melhor;
    }
};

C

#include <string.h>

int characterReplacement(char* s, int k) {
    int n = strlen(s);
    int contagens[26] = {0};
    int esquerda = 0, maior_freq = 0, melhor = 0;
    for (int direita = 0; direita < n; direita++) {
        int i = s[direita] - 'A';
        contagens[i]++;
        if (contagens[i] > maior_freq) maior_freq = contagens[i];
        int largura = direita - esquerda + 1;
        if (largura - maior_freq > k) {
            contagens[s[esquerda] - 'A']--;
            esquerda++;
        }
        if (direita - esquerda + 1 > melhor) melhor = direita - esquerda + 1;
    }
    return melhor;
}

Complexidade

  • Tempo: O(n) — uma varredura; o max_freq é atualizado em O(1) (não re-buscamos o máximo a cada passo — esse é o truque).
  • Espaço: O(1) — tabela fixa de 26 contagens (Python: um dict de no máximo 26 chaves).

Pegadinhas

  • Nunca decrementar maior_freq: o máximo é “histórico”. Isso é correto porque a janela só cresce ou “anda” (contração de 1) — decrementar faria a janela encolher e o resultado subestimar.
  • s é só maiúscula: s[i] - 'A' assume [0, 25]; se o enunciado aceitasse minúsculas/mistas (variação de entrevista), use tabela de 128/256 ou dict e ajuste os índices.
  • k pode ser maior que o tamanho da string → resposta = len(s) (funciona sem caso especial: a janela cresce até o fim sem invalidar).
  • A resposta no fim é len(s) − esquerda, não uma variável melhor (as duas convergem, mas a primeira dispensa o max extra por frame).
