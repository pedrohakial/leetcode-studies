Os 7 padrões-mãe (se tiver que decorar só uma coisa)

  1. Hash map troca busca O(n) por O(1) — complementos, contagens, índices.
  2. Dois ponteiros exploram ordenação/monotonicidade sem memória extra.
  3. Sliding window = two pointers que mantêm uma janela válida.
  4. BFS camadas = menor caminho sem peso; Dijkstra = com peso.
  5. Backtracking = DFS que faz, tenta, desfaz (escolhas).
  6. DP = subproblema ótimo + memo; ache a recorrência e a ordem de preenchimento.
  7. Ordenar primeiro — metade dos greedy/intervalos nasce de uma ordenação.
