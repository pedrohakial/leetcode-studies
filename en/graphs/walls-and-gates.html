286. Walls and Gates (Medium · Premium)

https://leetcode.com/problems/walls-and-gates/ · Topic: Multi-source BFS (Premium)

Problem (summary)

An m x n grid with -1 = wall, 0 = gate, 2147483647 (INF) = empty room. Fill each room with the minimum distance to the nearest gate (in orthogonal steps). Unreachable rooms stay INF. (Note: Premium problem — solve it through knowledge.)

INF INF 0   INF     3 -1 0  1
INF INF INF -1   2  2 1 -1
INF -1  INF -1  →  1 -1 2 -1
0   -1  INF INF    0 -1 3  4

Pattern — what to memorize

Multi-source BFS from ALL gates at once. When the queue starts with every gate (distance 0), the first time BFS touches a room it is from the nearest source — so rooms[room] = rooms[current] + 1 is already that room’s final answer. Every cell is visited exactly once.

Contrast with DFS-per-cell: the naive temptation is, for each room, to run a DFS/BFS looking for a gate — O((m·n)²) and re-exploring the same paths; the multi-source approach flips the question upside down (“for each gate, who is in the wave front?”) and costs O(m·n). Tell: “distance to the nearest of a set of sources” ⇒ reversed source: BFS leaving the sources, not the targets. Same pattern as Rotting Oranges — the difference is we record distance instead of time, and we mark rooms with the == INF test.

Python

class Solution:
    def wallsAndGates(self, rooms: list[list[int]]) -> None:
        from collections import deque
        if not rooms:
            return
        m, n = len(rooms), len(rooms[0])
        fila = deque()
        for i in range(m):
            for j in range(n):
                if rooms[i][j] == 0:
                    fila.append((i, j))            # MULTI-SOURCE BFS: all gates
        direcoes = ((1, 0), (-1, 0), (0, 1), (0, -1))
        while fila:
            r, c = fila.popleft()
            for dr, dc in direcoes:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and rooms[nr][nc] == 2**31 - 1:
                    rooms[nr][nc] = rooms[r][c] + 1  # distance = BFS level
                    fila.append((nr, nc))

Rust

#![allow(unused)]
fn main() {
impl Solution {
    pub fn walls_and_gates(rooms: &mut Vec<Vec<i32>>) {
        use std::collections::VecDeque;
        let (m, n) = (rooms.len(), rooms[0].len());
        let mut fila: VecDeque<(usize, usize)> = VecDeque::new();
        for i in 0..m {
            for j in 0..n {
                if rooms[i][j] == 0 {
                    fila.push_back((i, j)); // MULTI-SOURCE BFS: all gates
                }
            }
        }
        let direcoes = [(1isize, 0isize), (-1, 0), (0, 1), (0, -1)];
        while let Some((r, c)) = fila.pop_front() {
            for (dr, dc) in direcoes {
                let (nr, nc) = (r as isize + dr, c as isize + dc);
                if nr >= 0 && nr < m as isize && nc >= 0 && nc < n as isize {
                    let (nr, nc) = (nr as usize, nc as usize);
                    if rooms[nr][nc] == i32::MAX {
                        rooms[nr][nc] = rooms[r][c] + 1; // distance = BFS level
                        fila.push_back((nr, nc));
                    }
                }
            }
        }
    }
}
}

C++

#include <climits>
#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    void wallsAndGates(vector<vector<int>>& rooms) {
        int m = (int)rooms.size(), n = (int)rooms[0].size();
        queue<pair<int, int>> fila;
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j)
                if (rooms[i][j] == 0) fila.push({i, j}); // MULTI-SOURCE BFS: all
        int dirs[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        while (!fila.empty()) {
            auto [r, c] = fila.front();
            fila.pop();
            for (auto& d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && rooms[nr][nc] == INT_MAX) {
                    rooms[nr][nc] = rooms[r][c] + 1;   // distance = BFS level
                    fila.push({nr, nc});
                }
            }
        }
    }
};

C

#include <limits.h>
#include <stdlib.h>

void wallsAndGates(int** rooms, int roomsSize, int* roomsColSize) {
    if (roomsSize == 0) return;
    int cols = roomsColSize[0];
    int* fila = malloc((size_t)roomsSize * cols * sizeof(int));
    int frente = 0, tras = 0;
    for (int i = 0; i < roomsSize; i++)
        for (int j = 0; j < cols; j++)
            if (rooms[i][j] == 0) fila[tras++] = i * cols + j; /* MULTI-SOURCE BFS */
    int dirs[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
    while (frente < tras) {
        int pos = fila[frente++];
        int r = pos / cols, c = pos % cols;
        for (int d = 0; d < 4; d++) {
            int nr = r + dirs[d][0], nc = c + dirs[d][1];
            if (nr >= 0 && nr < roomsSize && nc >= 0 && nc < cols
                && rooms[nr][nc] == INT_MAX) {
                rooms[nr][nc] = rooms[r][c] + 1;   /* distance = BFS level */
                fila[tras++] = nr * cols + nc;
            }
        }
    }
    free(fila);
}

Complexity

  • Time: O(m·n) — each room enters the queue at most once, marked on first visit.
  • Space: O(m·n) — the queue in the worst case; everything in place (mutates the input).

Pitfalls

  • The “unvisited” test is rooms[nr][nc] == INF — mark with +1 over the current value and push to the queue at the same time (otherwise it gets re-enqueued).
  • Don’t use a separate visited[]: INF is the natural marker; gates (0) and walls (-1) are never overwritten.
  • Grid with no gates ⇒ nothing changes (queue empty from the start).
  • C: INT_MAX (2147483647) comes from <limits.h> — roomsColSize[0] must be passed (it isn’t optional like in problems without a 2D grid).
  • Rust/C++: could rooms[r][c] + 1 reach 2^31 − 1 + 1? No — reachable cells only get values ≤ m·n, far below INT_MAX; the == i32::MAX guard prevents writing into already marked cells.
