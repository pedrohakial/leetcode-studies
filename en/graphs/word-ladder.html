127. Word Ladder (Hard)

https://leetcode.com/problems/word-ladder/ · Topic: Graphs · BFS (minimum steps)

Problem (summary)

Given beginWord, endWord, and a word list, transform beginWord into endWord by changing one letter per step, with every intermediate word in the list. Return the total number of words in the shortest path (including the start and end), or 0 if no path exists.

beginWord = "hit", endWord = "cog",
wordList = ["hot","dot","dog","lot","log","cog"]
→ 5  ("hit" → "hot" → "dot" → "dog" → "cog")

Pattern — what to memorize

BFS on an implicit graph: each word is a node; two nodes are neighbors if they differ in 1 character. “Shortest path from A to B in an unweighted graph” is layered BFS — the level at which endWord is first discovered is the answer. Generate neighbors by character substitution (26×L candidates per word) instead of comparing against the whole list (N comparisons). BFS guarantees the minimum because it explores by level.

Bidirectional (interview bonus): run BFS from BOTH ends (start and goal) and stop when the fronts meet — it halves the search space: the number of visited states drops from b^d to 2·b^(d/2). The required solution here is plain BFS; bidirectional is the natural upgrade to mention.

Python

from collections import deque

class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: list[str]) -> int:
        palavras = set(wordList)
        if endWord not in palavras:
            return 0
        fila = deque([(beginWord, 1)])
        while fila:
            atual, passo = fila.popleft()
            if atual == endWord:
                return passo
            for i in range(len(atual)):
                for c in "abcdefghijklmnopqrstuvwxyz":
                    if c == atual[i]:
                        continue
                    nova = atual[:i] + c + atual[i + 1:]
                    if nova in palavras:
                        palavras.remove(nova)     # mark visited in the set
                        fila.append((nova, passo + 1))
        return 0

Removing from the set IS the visited mark: a discovered word can’t be rediscovered at a deeper level (BFS discovers at the minimum level). String slicing atual[:i] + c + atual[i+1:] is the Python way to swap one char (strings are immutable).

Rust

#![allow(unused)]
fn main() {
use std::collections::{HashSet, VecDeque};

impl Solution {
    pub fn ladder_length(begin_word: String, end_word: String, word_list: Vec<String>) -> i32 {
        let mut palavras: HashSet<String> = word_list.into_iter().collect();
        if !palavras.contains(&end_word) {
            return 0; // goal not in the list
        }
        let mut fila: VecDeque<(String, i32)> = VecDeque::new();
        fila.push_back((begin_word, 1));
        while let Some((atual, passo)) = fila.pop_front() {
            if atual == end_word {
                return passo;
            }
            let mut bytes: Vec<u8> = atual.bytes().collect();
            for i in 0..bytes.len() {
                let original = bytes[i];
                for c in b'a'..=b'z' {
                    if c == original {
                        continue;
                    }
                    bytes[i] = c; // generate the neighbor
                    let nova = String::from_utf8(bytes.clone()).unwrap();
                    if palavras.remove(&nova) { // mark visited
                        fila.push_back((nova, passo + 1));
                    }
                }
                bytes[i] = original; // restore
            }
        }
        0 // unreachable goal
    }
}
}

C++

#include <queue>
#include <string>
#include <unordered_set>
#include <utility>
using namespace std;

class Solution {
public:
    int ladderLength(string beginWord, string endWord, vector<string>& wordList) {
        unordered_set<string> palavras(wordList.begin(), wordList.end());
        if (!palavras.count(endWord)) return 0;  // goal not in the list
        queue<pair<string, int>> fila;
        fila.push({beginWord, 1});
        while (!fila.empty()) {
            auto [atual, passo] = fila.front();
            fila.pop();
            if (atual == endWord) return passo;
            for (int i = 0; i < (int)atual.size(); ++i) {
                char original = atual[i];
                for (char c = 'a'; c <= 'z'; ++c) {
                    if (c == original) continue;
                    atual[i] = c;                     // generate the neighbor
                    if (palavras.count(atual)) {
                        palavras.erase(atual);        // mark visited
                        fila.push({atual, passo + 1});
                    }
                }
                atual[i] = original;                  // restore
            }
        }
        return 0;                                     // unreachable goal
    }
};

C

#include <stdlib.h>
#include <string.h>

typedef struct { const char* palavra; int nivel; } ItemFila;

int ladderLength(char* beginWord, char* endWord, char** wordList, int wordListSize) {
    int tamanho = (int)strlen(beginWord);
    int fim = -1;
    for (int i = 0; i < wordListSize; i++)
        if (strcmp(wordList[i], endWord) == 0) { fim = i; break; }
    if (fim == -1) return 0;                         /* the goal is not on the list */

    int* visitado = calloc(wordListSize, sizeof(int));
    for (int i = 0; i < wordListSize; i++)
        if (strcmp(wordList[i], beginWord) == 0) visitado[i] = 1;

    ItemFila* fila = malloc((wordListSize + 1) * sizeof(ItemFila));
    int frente = 0, tras = 0;
    fila[tras].palavra = beginWord;
    fila[tras].nivel = 1;
    tras++;

    while (frente < tras) {
        ItemFila atual = fila[frente++];
        if (strcmp(atual.palavra, endWord) == 0) {
            free(visitado);
            free(fila);
            return atual.nivel;
        }
        for (int i = 0; i < wordListSize; i++) {
            if (visitado[i]) continue;
            int difs = 0;                            /* count char differences */
            for (int c = 0; c < tamanho && difs <= 1; c++)
                if (wordList[i][c] != atual.palavra[c]) difs++;
            if (difs == 1) {
                visitado[i] = 1;
                fila[tras].palavra = wordList[i];
                fila[tras].nivel = atual.nivel + 1;
                tras++;
            }
        }
    }
    free(visitado);
    free(fila);
    return 0;                                        /* unreachable goal */
}

With no free mutable strings, C generates neighbors differently: scan the list comparing char by char (counting differences) — an implicit graph by checking rather than generating. visitado[] plays the role of the set; the queue points into the list’s own strings (no copies).

Complexity

  • Time: O(N·L·26), with N = words and L = length — each word is discovered once and generates 26·L candidates (in practice each generation costs O(L) of string → O(N·L²) counting the strings; the C diff-counting version is O(N·L) per pop).
  • Space: O(N·L) — the word set plus the queue in the worst case.

Pitfalls

  • endWord outside the list → immediate 0 (check before the BFS).
  • Mark visited at discovery time (not at pop): otherwise the same word enters the queue many times, exploding the BFS.
  • Words have fixed length; the substitution respects position — never remove/insert characters.
  • beginWord may not be in the list — BFS starts from it anyway (what matters is marking the list’s words). If beginWord == endWord and both are in the list, answer 1 (the initial level).
  • Rust: String::from_utf8(...).unwrap() is safe because only one ASCII byte is mutated; with real Unicode, build a Vec<char>.
  • C: difs <= 1 in the loop cuts the counting early — a legitimate micro-optimization, but keep the difs == 1 logic in the decision.
