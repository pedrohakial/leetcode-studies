215. Kth Largest Element in an Array (Medium)

https://leetcode.com/problems/kth-largest-element-in-an-array/ · Topic: Heap / Quickselect

Problem (summary)

Array nums (unsorted) and integer k; return the k-th largest element. Duplicates count as distinct elements. The array does not need to come back sorted.

nums = [3,2,1,5,6,4], k = 2  →  5   (the 2nd largest)
nums = [3,2,3,1,2,4,5,5,6], k = 4  →  4

Pattern — what to memorize

Two algorithms for the same target:

  1. Min-heap of size k (O(n log k), the interview mainstay): keep only the k largest seen. For each x, if the heap has fewer than k, push; otherwise, if x > top (the SMALLEST of the k), replace the top. At the end the top is the k-th largest. Memorize: heap always at size k, root = the answer.
  2. Quickselect (O(n) average, O(n²) worst): partition (Lomuto) and throw away half each step — only descend into the side containing index k−1 (in descending partition). It’s “quicksort that only sorts what it needs”.

Clues: k-th largest/smallest in an unsorted array ⇒ a size-k heap is the universal pattern (and it’s O(1) extra space besides the heap); if they ask for O(n) average or “no extra memory” ⇒ quickselect. Interview bonus (Python):

def kthLargestQuickselect(nums: list[int], k: int) -> int:
    # Lomuto with the pivot at the end; DESCENDING partitions leave the
    # k-th largest at index k-1.
    def parte(l: int, r: int) -> int:
        pivô = nums[r]
        i = l
        for j in range(l, r):
            if nums[j] > pivô:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
        nums[i], nums[r] = nums[r], nums[i]
        return i

    alvo = k - 1
    l, r = 0, len(nums) - 1
    while True:
        p = parte(l, r)
        if p == alvo:
            return nums[p]
        if p < alvo:
            l = p + 1           # the k-th is on the larger side (right)
        else:
            r = p - 1

Python

class Solution:
    def findKthLargest(self, nums: list[int], k: int) -> int:
        import heapq
        heap = nums[:k]                        # only the k largest matter
        heapq.heapify(heap)                    # min-heap of size k
        for x in nums[k:]:
            heapq.heappushpop(heap, x)         # if x > the smallest of the k, it enters
        return heap[0]                         # root = k-th largest

Rust

#![allow(unused)]
fn main() {
impl Solution {
    pub fn find_kth_largest(nums: Vec<i32>, k: i32) -> i32 {
        use std::cmp::Reverse;
        use std::collections::BinaryHeap;
        // BinaryHeap is a MAX-heap; Reverse turns it into the size-k min-heap
        let mut heap: BinaryHeap<Reverse<i32>> = BinaryHeap::new();
        for &x in nums.iter().take(k as usize) {
            heap.push(Reverse(x));
        }
        for &x in nums.iter().skip(k as usize) {
            if x > heap.peek().unwrap().0 {    // if x > the smallest of the k, it enters
                heap.pop();
                heap.push(Reverse(x));
            }
        }
        heap.peek().unwrap().0                 // top (smallest) = k-th largest
    }
}
}

C++

#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        priority_queue<int, vector<int>, greater<int>> heap; // min-heap of size k
        for (int x : nums) {
            if ((int)heap.size() < k) {
                heap.push(x);
            } else if (x > heap.top()) {       // if x > the smallest of the k, it enters
                heap.pop();
                heap.push(x);
            }
        }
        return heap.top();                     // top (smallest) = k-th largest
    }
};

C

#include <stdlib.h>

/* Hand-rolled binary min-heap — bubble up/down from an index. */
static void subir(int* heap, int i) {
    while (i > 0) {
        int pai = (i - 1) / 2;
        if (heap[pai] <= heap[i]) break;
        int t = heap[pai]; heap[pai] = heap[i]; heap[i] = t;
        i = pai;
    }
}

static void descer(int* heap, int tam, int i) {
    for (;;) {
        int menor = i, e = 2 * i + 1, d = 2 * i + 2;
        if (e < tam && heap[e] < heap[menor]) menor = e;
        if (d < tam && heap[d] < heap[menor]) menor = d;
        if (menor == i) break;
        int t = heap[i]; heap[i] = heap[menor]; heap[menor] = t;
        i = menor;
    }
}

int findKthLargest(int* nums, int numsSize, int k) {
    int* heap = malloc((size_t)k * sizeof(int));
    int tam = 0;
    for (int i = 0; i < numsSize; i++) {
        if (tam < k) {                          /* fill the heap up to k */
            heap[tam] = nums[i];
            subir(heap, tam);
            tam++;
        } else if (nums[i] > heap[0]) {         /* x > the smallest of the k: replace */
            heap[0] = nums[i];
            descer(heap, tam, 0);
        }
    }
    int resp = heap[0];                         /* root = k-th largest */
    free(heap);
    return resp;
}

Complexity

  • Time: heap → O(n log k) (O(log k) push/pop per element; building the initial heap with the first k is O(k)); quickselect → O(n) average, O(n²) worst case (bad pivot).
  • Space: heap → O(k); quickselect → O(log n) of recursion (or O(1) iterative — in-place, mutates the input).

Pitfalls

  • k = 1 (largest) and k = n (smallest) work with the same code — test both.
  • Duplicates: the heap counts separate occurrences — the algorithm does not deduplicate (correct per the statement).
  • Languages diverge on heap kind: Rust BinaryHeap is a max-heap → use std::cmp::Reverse (or negate) to make it a min-heap; C++ priority_queue is a max-heap → greater<int> for min; Python heapq is min by default (no inversion); C: hand-rolled min-heap (implement subir/descer).
  • Don’t sort the whole array and take nums[n-k]: O(n log n) — slower, and the interviewer expects the heap/quickselect.
  • Quickselect: picking the pivot from the end (Lomuto) is simple but O(n²) on an already-sorted array; mention median-of-three as an improvement.
  • Rust: heap.peek().unwrap() once the heap is guaranteed to have k elements — use .0 on the Reverse for the value.
