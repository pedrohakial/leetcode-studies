212. Word Search II (Hard)

https://leetcode.com/problems/word-search-ii/ · Tópico: Trie + Backtracking

Enunciado (resumo)

Dado um tabuleiro m×n de letras e uma lista words, devolver todas as palavras que podem ser formadas por células adjacentes (4 direções), cada célula usada no máximo uma vez por palavra. Palavras distintas devem sair uma única vez; qualquer ordem de saída vale.

board = [o a a n]  words = ["oath","pea","eat","rain"]  →  ["oath","eat"]
        [e t a e]
        [i h k r]
        [i f l v]
board = [a b]  words = ["abcb"]  →  []
        [c d]

Padrão — o que decorar

Trie de TODAS as palavras + uma travessia do grid (não uma por palavra). O porquê: resolver “por palavra” (Word Search I para cada palavra) custa O(W · m·n·3^L) — W palavras, para cada uma m·n inícios e até 3^(L-1) ramos por célula (4 direções, menos a de onde veio). A trie inverte isso: uma única DFS por célula de início, e o que se caminha é o PREFIXO compartilhado — palavras com o mesmo começo são exploradas juntas; sem prefixo em comum, o ramo morre. Além da poda de folhas mortas (nó sem filhos e sem palavra é removido do pai após ser explorado) — cada palavra só pode ser achada uma vez, então sua folha “morta” não é revisitada; isso derruba o custo real para bem menos que o pior caso. Pista: “lista de palavras + grid” → buildar a trie primeiro é o reflexo que diferencia o Hard.

Python

class Solution:
    def findWords(self, board: list[list[str]], words: list[str]) -> list[str]:
        class NoTrie:
            def __init__(self):
                self.filhos: dict[str, NoTrie] = {}
                self.palavra: str | None = None     # palavra que termina aqui

        raiz = NoTrie()
        for palavra in words:
            no = raiz
            for ch in palavra:
                no = no.filhos.setdefault(ch, NoTrie())
            no.palavra = palavra

        resp: list[str] = []
        m, n = len(board), len(board[0])

        def dfs(i: int, j: int, no: NoTrie) -> None:
            if no.palavra is not None:
                resp.append(no.palavra)
                no.palavra = None                    # não repetir a palavra
            if not no.filhos:
                return                               # folha: nada a explorar
            original = board[i][j]
            board[i][j] = '#'                        # marca visitado
            for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n:
                    letra = board[ni][nj]
                    filho = no.filhos.get(letra)
                    if filho is not None:
                        dfs(ni, nj, filho)
                        if not filho.filhos and filho.palavra is None:
                            del no.filhos[letra]     # poda folha morta
            board[i][j] = original

        for i in range(m):
            for j in range(n):
                letra = board[i][j]
                filho = raiz.filhos.get(letra)
                if filho is not None:
                    dfs(i, j, filho)
                    if not filho.filhos and filho.palavra is None:
                        del raiz.filhos[letra]
        return resp

Rust

#![allow(unused)]
fn main() {
#[derive(Default)]
struct NoTrie212 {
    filhos: [Option<Box<NoTrie212>>; 26],
    palavra: Option<String>,
}

impl Solution {
    pub fn find_words(board: Vec<Vec<char>>, words: Vec<String>) -> Vec<String> {
        let mut raiz = NoTrie212::default();
        for palavra in &words {
            let mut no = &mut raiz;
            for &b in palavra.as_bytes() {
                let i = (b - b'a') as usize;
                no = no.filhos[i].get_or_insert_with(|| Box::new(NoTrie212::default()));
            }
            no.palavra = Some(palavra.clone());
        }

        let mut resp = Vec::new();
        let mut tab = board;
        let (m, n) = (tab.len(), tab[0].len());
        let dirs = [(1i32, 0i32), (-1, 0), (0, 1), (0, -1)];

        fn dfs(
            i: usize,
            j: usize,
            no: &mut NoTrie212,
            tab: &mut Vec<Vec<char>>,
            m: usize,
            n: usize,
            dirs: &[(i32, i32)],
            resp: &mut Vec<String>,
        ) {
            if let Some(p) = no.palavra.take() {
                resp.push(p); // palavra achada: não repetir (take)
            }
            if no.filhos.iter().all(|f| f.is_none()) {
                return; // folha morta (será podada pelo pai)
            }
            let original = tab[i][j];
            tab[i][j] = '#';
            for &(di, dj) in dirs {
                let ni = i as i32 + di;
                let nj = j as i32 + dj;
                if ni < 0 || nj < 0 || ni >= m as i32 || nj >= n as i32 {
                    continue;
                }
                let (ni, nj) = (ni as usize, nj as usize);
                let letra = tab[ni][nj];
                if letra == '#' {
                    continue; // célula já visitada neste caminho
                }
                let idx = (letra as u8 - b'a') as usize;
                let podar = if let Some(filho) = no.filhos[idx].as_mut() {
                    dfs(ni, nj, filho, tab, m, n, dirs, resp);
                    filho.filhos.iter().all(|f| f.is_none()) && filho.palavra.is_none()
                } else {
                    false
                };
                if podar {
                    no.filhos[idx] = None; // poda de folha morta
                }
            }
            tab[i][j] = original;
        }

        for i in 0..m {
            for j in 0..n {
                let letra = tab[i][j];
                let idx = (letra as u8 - b'a') as usize;
                let podar = if let Some(filho) = raiz.filhos[idx].as_mut() {
                    dfs(i, j, filho, &mut tab, m, n, &dirs, &mut resp);
                    filho.filhos.iter().all(|f| f.is_none()) && filho.palavra.is_none()
                } else {
                    false
                };
                if podar {
                    raiz.filhos[idx] = None;
                }
            }
        }
        resp
    }
}
}

C++

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> findWords(vector<vector<char>>& board, vector<string>& words) {
        for (const string& palavra : words) {
            No* no = &raiz;
            for (char ch : palavra) {
                int i = ch - 'a';
                if (!no->filhos[i]) no->filhos[i] = new No();
                no = no->filhos[i];
            }
            no->palavra = palavra; // palavra que termina aqui
        }
        vector<string> resp;
        int m = (int)board.size(), n = (int)board[0].size();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                char letra = board[i][j];
                No* filho = raiz.filhos[letra - 'a'];
                if (filho) {
                    dfs(i, j, filho, board, resp);
                    if (morta(filho)) raiz.filhos[letra - 'a'] = nullptr; // poda
                }
            }
        }
        return resp;
    }

private:
    struct No {
        No* filhos[26] = {};
        string palavra; // vazia = não é fim; não vazia = palavra completa
        ~No() {
            for (auto* f : filhos) delete f;
        }
    };
    No raiz;

    static bool morta(const No* no) {
        for (auto* f : no->filhos)
            if (f) return false;
        return no->palavra.empty();
    }

    static void dfs(int i, int j, No* no, vector<vector<char>>& board, vector<string>& resp) {
        if (!no->palavra.empty()) {
            resp.push_back(no->palavra);
            no->palavra.clear(); // palavra já coletada: não repetir
        }
        if (morta(no)) return; // folha morta (será podada pelo pai)
        int m = (int)board.size(), n = (int)board[0].size();
        char original = board[i][j];
        board[i][j] = '#';
        int dirs[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        for (auto& d : dirs) {
            int ni = i + d[0], nj = j + d[1];
            if (ni < 0 || nj < 0 || ni >= m || nj >= n) continue;
            char letra = board[ni][nj];
            if (letra == '#') continue; // já visitado neste caminho
            No* filho = no->filhos[letra - 'a'];
            if (filho) {
                dfs(ni, nj, filho, board, resp);
                if (morta(filho)) no->filhos[letra - 'a'] = nullptr; // poda
            }
        }
        board[i][j] = original;
    }
};

C

#include <stdbool.h>
#include <stdlib.h>
#include <string.h>

typedef struct NoTrie212 {
    struct NoTrie212* filhos[26];
    const char* palavra; /* palavra que termina aqui; NULL = não é fim */
} NoTrie212;

typedef struct {
    NoTrie212 raiz;
} Trie212;

static NoTrie212* trie_no_novo(void) {
    return (NoTrie212*)calloc(1, sizeof(NoTrie212));
}

static bool trie_morta(const NoTrie212* no) {
    if (no->palavra) return false;
    for (int i = 0; i < 26; i++)
        if (no->filhos[i]) return false;
    return true;
}

static char* duplicar(const char* s) {
    size_t n = strlen(s);
    char* copia = (char*)malloc(n + 1);
    memcpy(copia, s, n + 1);
    return copia;
}

static void busca212(int i, int j, NoTrie212* no, char** tab, int m, int n,
                     char** resp, int* returnSize) {
    if (no->palavra) {
        resp[(*returnSize)++] = duplicar(no->palavra);
        no->palavra = NULL; /* não repetir a palavra */
    }
    if (trie_morta(no)) return; /* folha morta (poda pelo pai) */
    char original = tab[i][j];
    tab[i][j] = '#';
    int dirs[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
    for (int d = 0; d < 4; d++) {
        int ni = i + dirs[d][0], nj = j + dirs[d][1];
        if (ni < 0 || nj < 0 || ni >= m || nj >= n) continue;
        unsigned char letra = (unsigned char)tab[ni][nj];
        if (letra == '#') continue; /* já visitado neste caminho */
        NoTrie212* filho = no->filhos[letra - 'a'];
        if (filho) {
            busca212(ni, nj, filho, tab, m, n, resp, returnSize);
            if (trie_morta(filho)) no->filhos[letra - 'a'] = NULL; /* poda */
        }
    }
    tab[i][j] = original;
}

static void trie_liberar(NoTrie212* no) {
    for (int i = 0; i < 26; i++)
        if (no->filhos[i]) trie_liberar(no->filhos[i]);
    free(no);
}

char** findWords(char** board, int boardSize, int* boardColSize,
                 char** words, int wordsSize, int* returnSize) {
    Trie212 trie;
    memset(&trie, 0, sizeof(trie));
    for (int w = 0; w < wordsSize; w++) {
        NoTrie212* no = &trie.raiz;
        for (char* c = words[w]; *c; c++) {
            int i = (unsigned char)*c - 'a';
            if (!no->filhos[i]) no->filhos[i] = trie_no_novo();
            no = no->filhos[i];
        }
        no->palavra = words[w]; /* aponta para a string original (vive aqui) */
    }

    char** resp = (char**)malloc(wordsSize * sizeof(char*));
    *returnSize = 0;
    for (int i = 0; i < boardSize; i++) {
        for (int j = 0; j < boardColSize[i]; j++) {
            unsigned char letra = (unsigned char)board[i][j];
            NoTrie212* filho = trie.raiz.filhos[letra - 'a'];
            if (filho) {
                busca212(i, j, filho, board, boardSize, boardColSize[0],
                         resp, returnSize);
                if (trie_morta(filho)) trie.raiz.filhos[letra - 'a'] = NULL; /* poda */
            }
        }
    }
    for (int i = 0; i < 26; i++)
        if (trie.raiz.filhos[i]) trie_liberar(trie.raiz.filhos[i]);
    return resp;
}

Complexidade

  • Build da trie: O(Σ|palavras|) — cada letra de cada palavra vira um nó (no pior caso).
  • Busca: pior caso O(m · n · 4 · 3^(L-1)), L = maior palavra — cada célula inicia um DFS que ramifica em ≤ 4 e continua em ≤ 3 direções (a de onde veio não volta). Sem a trie (Word Search I por palavra) seria O(W · m·n·3^L) — o fator W some. Com a poda de folhas mortas, o custo prático é muito menor (ramos sem prefixo em comum morrem no primeiro passe).
  • Espaço: O(26 · Σ|palavras|) da trie + O(m·n) de visitado (o marker '#' é in-place) + O(L) da pilha do DFS.

Pegadinhas

  • O guard do '#' é OBRIGATÓRIO fora do Python: dict.get('#') devolve None e protege sozinho, mas em Rust/C++/C indexar a célula visitada '#' - 'a' estoura o array (índice 194, panic/UB) — o bug real que este código já teve, corrigido com if letra == '#' { continue; } antes do índice.
  • Palavras duplicadas saem UMA vez: zerar no.palavra (take/clear/NULL) no momento da coleta — sem isso, o mesmo caminho acharia a palavra de novo.
  • Restaurar o tabuleiro: original = tab[i][j]; tab[i][j] = '#'; ...; tab[i][j] = original; em TODOS os retornos — esquecer a restauração contamina os caminhos irmãos do DFS.
  • Poda de folhas mortas: só depois de explorar o filho; um nó com palavra ainda pendente NÃO pode ser podado (a morta() exige palavra vazia também).
  • C: a resposta é alocada com wordsSize ponteiros (teto de palavras distintas) e cada palavra é copiada (duplicar) — a trie guarda ponteiros para words, que o juiz não libera antes.
  • Ordem de saída é livre — os testes do LeetCode comparam conjuntos; não gaste um sort desnecessário.
